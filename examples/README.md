# Generated examples

All image files in this folder are synthetic. They were generated by `change_watch/demo.py` with seed 42. They have no geographic coordinates, acquisition dates or real-world mining evidence.

- `synthetic_before.png`: illustrative original terrain.
- `synthetic_after.png`: the same terrain with an artificial expanded region.
- `synthetic_truth.png`: exact generated change mask.
- `synthetic_preview.png`: before, after and flagged overlay for the README.
