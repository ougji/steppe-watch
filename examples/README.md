# Generated examples

All image files in this folder are synthetic. The original pair was generated by `change_watch/demo.py` with seed 42. They have no geographic coordinates, acquisition dates or real-world mining evidence.

- `synthetic_before.png`: illustrative original terrain.
- `synthetic_after.png`: the same terrain with an artificial expanded region.
- `synthetic_truth.png`: exact generated change mask.
- `synthetic_preview.png`: before, after and flagged overlay for the README.
- `synthetic_after_brightness.png`: `synthetic_after.png` with +45 added to every RGB channel, using signed arithmetic and clipping at 255; the truth mask is unchanged.
- `benchmark.json`: compares both scenarios under the same detector settings. These are two variants of one generated scene, not independent evaluation sites.

Run from the repository directory:

```bash
python -m change_watch.benchmark examples/benchmark.json --out outputs/benchmark
```
